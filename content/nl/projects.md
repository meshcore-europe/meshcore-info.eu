Elk project linkt naar de code of, als de code niet openbaar is, naar de site. Heeft de
code een licentie, dan zie je die erbij. Elk project komt van zijn eigen makers. Documentatie en
ondersteuning vind je daarom op de pagina van het project zelf. Een firmwarefork is een aangepaste kopie van
MeshCore. Het is niet de officiële firmware en kan zich anders gedragen. MeshCore-nodes hebben
rollen: een companion is de radio waarmee je berichten stuurt, een repeater stuurt berichten door,
een room server beheert een gedeeld prikbord en een observer uploadt wat hij hoort.

Deze pagina is een selectie. Een langere lijst vind je op
[awesome-meshcore](https://meshcore.live/).
