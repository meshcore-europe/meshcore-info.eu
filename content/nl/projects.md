Elk project linkt naar zijn code of, als de code niet openbaar is, naar zijn site. Heeft de code een licentie, dan staat die erbij. Elk project komt van zijn eigen makers, dus de documentatie en de ondersteuning vind je op hun eigen pagina. Een firmwarefork is een aangepaste kopie van MeshCore, niet de officiële firmware, en kan zich anders gedragen. MeshCore-nodes hebben rollen: een companion is de radio waarmee je berichten stuurt, een repeater geeft berichten door, een room server houdt een gedeeld prikbord bij, en een observer uploadt wat hij hoort.
