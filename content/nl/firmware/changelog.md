De nieuwste release staat bovenaan. Bij elke release lees je in gewone woorden wat er voor je node verandert. Dat kan een companion zijn (de node waarmee je berichten stuurt), een repeater (die geeft berichten door) of een room server (die bewaart berichten voor een groep). In de officiële release notes vind je alle details. Deze site volgt de standaardversie van MeshCore.
