Every project links to its code or, when the code is not public, to its site. A licence shows when the
code has one. Each comes from its own makers, so its own page has the
documentation and the support. A firmware fork is a changed copy of MeshCore, not the official
firmware, and can behave differently. MeshCore nodes have roles: a companion
is the radio you message from, a repeater passes messages on, a room server
keeps a shared message board, and an observer uploads what it hears.

This page is a selection. For a longer list, see
[awesome-meshcore](https://meshcore.live/).
