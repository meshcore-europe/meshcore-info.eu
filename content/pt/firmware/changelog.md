As mais recentes aparecem primeiro. Cada versão explica em palavras simples o que muda para o teu nó:
um companion (o nó com que envias mensagens), um repetidor (reencaminha as mensagens) ou
um room server (guarda as mensagens de um grupo). As notas oficiais têm todos os
pormenores. Este site segue o MeshCore original.
