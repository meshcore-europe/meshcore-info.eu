## O que este site não faz {#not}

- Não corre scripts de análise, estatísticas ou rastreio, nossos ou de terceiros.
- Carrega as fontes, os estilos e os scripts apenas deste site. Não há
  vídeos incorporados de outros sites, nem botões de redes sociais, nem anúncios.
- Não tem contas nem comentários. Os dois formulários do site, o gerador
  de chaves e o seletor de canais, não nos enviam nada.

## O que fica no teu browser {#browser}

Quando escolhes seguir o sistema, escuro ou claro no menu de tema, o teu browser
guarda essa escolha num cookie chamado `dmc-mode` durante 1 ano. O cookie é
definido em meshcore-info.eu e nos seus subdomínios. Assim, cada página abre como escolheste.
O cookie guarda apenas essa palavra. Se nunca escolheres, o site não define nenhum cookie.
Para o remover, apaga os dados do site no teu browser.

A página inicial também regista, neste separador, que já viste o filme de abertura.
Assim, uma segunda visita no mesmo separador abre logo no conteúdo. Esse registo
desaparece quando fechas o separador.

Numa página com uma lista de verificação, como a
[lista de verificação de instalação](/repeater-guide/#checklist), o teu browser guarda os
itens que marcaste. Assim, continuam marcados quando voltas. Ficam no
teu dispositivo até os desmarcares.

A página inicial lê as línguas preferidas do teu browser e abre a
versão do site na língua correspondente. Essa verificação corre no teu browser e
não envia nada. Depois de a página escolher uma língua, ou de tu escolheres uma no
menu de línguas, o teu browser guarda essa língua no teu dispositivo. Da próxima vez,
a página inicial abre nessa língua, sem a nota sobre a língua.
Para a remover, apaga os dados do site no teu browser.

## O que o site pede a outros servidores {#requests}

A página inicial e a página Rede mostram números em tempo real de
[meshcore-analyzer.eu](https://meshcore-analyzer.eu). Esse servidor é gerido pelo
mesmo grupo de voluntários. A página Encontrar canais pede a esse servidor os canais do
país que escolhes. Cada pedido leva o teu endereço IP, o nome e a versão do teu
browser (o user agent) e, em Encontrar canais, o país que escolheste. Nenhuma
outra página contacta outro servidor.

## O que o nosso alojamento vê {#host}

A Cloudflare, uma empresa de alojamento, envia-te cada página. Para te enviar uma página,
os servidores da Cloudflare tratam o teu pedido. Esse pedido inclui o teu endereço IP,
o endereço da página e o user agent do teu browser, como em qualquer
servidor web. A [política de privacidade](https://www.cloudflare.com/privacypolicy/)
da Cloudflare descreve como trata esses dados. A Cloudflare também pede ao teu browser
que lhe comunique as ligações falhadas, para poder detetar falhas de serviço.

Os voluntários que gerem este site não ativam a análise web da Cloudflare
e não têm acesso a registos de visitantes individuais.

## Ligações para outros sites {#links}

As ligações neste site levam a grupos locais, mapas, projetos, fabricantes e
ao GitHub. Quando segues uma, aplica-se a política de privacidade desse site. As
ligações "Editar esta página no GitHub" levam-te ao GitHub.

alguma coisa nesta página não estiver clara ou já não for verdade.
