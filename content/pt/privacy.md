## O que este site não faz {#not}

- Não corre scripts de análise, estatísticas ou rastreio, nossos ou de terceiros.
- Carrega os tipos de letra, estilos e scripts apenas a partir deste site. Não há vídeos incorporados de outros sites, botões de redes sociais nem anúncios publicitários.
- Não tem contas nem comentários. Os dois formulários do site, o gerador de chaves e o seletor de canais, não nos enviam nada.

## O que fica no teu navegador {#browser}

Quando escolhes seguir o sistema, escuro ou claro no menu de tema, o teu navegador guarda essa escolha num cookie chamado `dmc-mode` durante 1 ano. O cookie é definido em meshcore-info.eu e nos seus subdomínios, para que cada página abra como escolheste. O cookie guarda apenas essa palavra. Se nunca escolheres, o site não define nenhum cookie. Limpa os dados de sites do teu navegador para o remover.

A página inicial também lembra, neste separador, que viste o filme de abertura, por isso uma segunda visita no mesmo separador abre no conteúdo. Essa nota desaparece quando fechas o separador.

Numa página com uma lista de verificação, como a [lista de verificação para instalação](/repeater-guide/#checklist), o teu navegador guarda os itens que marcaste, para que continuem marcados quando voltares. Ficam no teu dispositivo até os desmarcares.

A página de entrada lê as línguas preferidas do teu navegador e abre a versão do site na língua correspondente. Essa verificação corre no teu navegador; nada é guardado nem enviado.

## O que o site pede a outros servidores {#requests}

A página inicial e a página Rede mostram números em direto de [meshcore-analyzer.eu](https://meshcore-analyzer.eu), gerido pelo mesmo grupo de voluntários. A página Encontrar canais pede a esse servidor os canais do país que escolhes. Cada pedido leva o teu endereço IP, o nome e a versão do teu navegador (o user agent) e, em Encontrar canais, o país que escolheste. Nenhuma outra página contacta outro servidor.

## O que o nosso alojamento vê {#host}

A Cloudflare, uma empresa de alojamento, envia-te cada página. Para te enviar uma página, os servidores da Cloudflare tratam o teu pedido. Esse pedido inclui o teu endereço IP, o endereço da página e o user agent do teu navegador, como em qualquer servidor web. A [política de privacidade](https://www.cloudflare.com/privacypolicy/) da Cloudflare descreve como trata esses dados. A Cloudflare também pede ao teu navegador que lhe comunique uma ligação falhada, para poder ver falhas no serviço.

Os voluntários que gerem este site não ativam as estatísticas web da Cloudflare e não têm acesso a registos de visitantes individuais.

## Ligações para outros sites {#links}

As ligações neste site levam a grupos locais, mapas, projetos, fabricantes e ao GitHub. Quando segues uma, aplica-se a política de privacidade desse site. As ligações "Editar esta página no GitHub" levam-te ao GitHub.
