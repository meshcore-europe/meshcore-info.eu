Cada projeto tem uma ligação para o seu código. Quando o código não é público, a ligação leva ao site do projeto. Se o código tiver licença, esta também aparece.
Cada projeto vem dos seus próprios criadores. Por isso, encontras a documentação e o suporte na página do projeto. Um fork de firmware é uma cópia alterada do MeshCore e não o firmware oficial. Pode comportar-se de forma diferente. Os nós MeshCore têm funções: o companion é o rádio a partir do qual envias mensagens. O repetidor reencaminha as mensagens. O room server mantém um quadro de mensagens partilhado. O observer envia para a internet o que ouve.

Esta página é uma seleção. Para uma lista mais longa, consulta o
[awesome-meshcore](https://meshcore.live/).
