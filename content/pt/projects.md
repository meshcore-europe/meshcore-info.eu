Cada projeto tem ligação para o seu código ou, quando o código não é público, para o seu site. A licença aparece quando o código a tem. Cada projeto vem dos seus próprios autores, por isso a documentação e o apoio estão na página deles. Um fork de firmware é uma cópia alterada do MeshCore, não o firmware oficial, e pode comportar-se de forma diferente. Os nós MeshCore têm funções: um companion é o rádio a partir do qual envias mensagens, um repetidor reencaminha mensagens, um room server mantém um quadro de mensagens partilhado e um observer envia para a nuvem o que ouve.
