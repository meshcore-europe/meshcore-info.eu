Cada proyecto enlaza a su código o, cuando el código no es público, a su sitio web. Si el código tiene licencia, aparece indicada. Cada proyecto viene de sus propios creadores, así que su propia página tiene la documentación y el soporte. Un fork de firmware es una copia modificada de MeshCore, no el firmware oficial, y puede comportarse de otra manera. Los nodos de MeshCore tienen roles: un companion es la radio desde la que envías mensajes, un repetidor reenvía mensajes, un room server mantiene un tablón de mensajes compartido y un observer sube lo que escucha.
