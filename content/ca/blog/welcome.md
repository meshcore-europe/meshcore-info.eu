meshcore-info.eu explica MeshCore per a Europa: la configuració, les guies i
les eines que comparteixen les meshes locals. Pots copiar lliurement la nota de premsa següent.

## Nota de premsa {#press-release}

Copia aquest text per al teu web de notícies, butlletí o xat de grup. Fes-lo servir tal com
està, o escurça'l. Cita meshcore-info.eu com a font, en minúscules i amb .eu.

**meshcore-info.eu reuneix la configuració, les guies i les eines de MeshCore per a Europa.**

**Qui i què.** MeshCore és una manera d'enviar missatges sense dependre de cap xarxa. Envia
textos curts per ràdio, de node a node, sense internet ni subscripció. Els repetidors, petites
ràdios LoRa, retransmeten cada missatge. La mesh continua funcionant durant una apagada o quan
cau internet, mentre els repetidors tinguin corrent. No transmet veu ni fotos,
i no substitueix els serveis d'emergència. El
22 d'octubre de 2026, meshcore-analyzer.eu havia detectat 30.240 repetidors a
Europa en 7 dies.

Els grups locals gestionen aquests repetidors. Fins ara, la seva configuració,
les guies i les eines estaven repartides per països o per comunitats. meshcore-info.eu
les reuneix per a Europa, en 33 llengües. L'escriuen voluntaris, sense anuncis,
enllaços a botigues ni seguiment.

**Com funciona.**

- Obre meshcore-info.eu en la teva llengua: el web n'ofereix 33.
- Consulta guies sobre [maquinari](/devices/), rols i [configuració](/guides/), i sobre
  [com funciona MeshCore](/about/).
- Busca el [grup local](/community/) més proper o afegeix el teu.
- Afegeix a [Configuració recomanada](/guides/settings/) la configuració que es fa servir a la teva zona.
- Corregeix qualsevol cosa del web, com en un wiki. Un voluntari revisa cada canvi
  abans que aparegui al web. A [Col·labora](/contribute/) hi veuràs com fer-ho, amb compte de GitHub
  o sense.

**Per què és important.** Comunitats de tot Europa fan servir MeshCore les unes al costat de les altres. Amb
la configuració adequada, les seves meshes formen una sola mesh.

## Els compromisos {#promises}

- **Sense anuncis ni enllaços a botigues o d'afiliació.** La pàgina [Dispositius](/devices/)
  mostra les especificacions dels fabricants i una franja de preus. No enllaça mai a cap
  botiga.
- **Sense seguiment.** El web no fa servir cap eina d'analítica ni de seguiment. L'única galeta recorda el
  tema que has triat. L'únic altre servidor al qual es connecta el web és meshcore-analyzer.eu,
  que gestionen els mateixos voluntaris. A la [pàgina de privadesa](/privacy/) trobaràs els detalls.
- **Fets amb fonts.** El que escrivim sobre MeshCore prové del seu firmware
  i de la seva documentació. Les normes de ràdio provenen dels reguladors.
- **El teu idioma.** El web està disponible en 33 idiomes. Les pàgines comencen com a
  traduccions automàtiques, i les marquem així fins que un parlant nadiu les ha revisat.
