Chaque projet renvoie vers son code ou, quand le code n'est pas public, vers son site. Une licence apparaît quand le code en a une. Chaque projet vient de ses propres auteurs, donc sa propre page contient la documentation et le support. Un fork de micrologiciel est une copie modifiée de MeshCore, pas le micrologiciel officiel, et peut se comporter différemment. Les nœuds MeshCore ont des rôles : un companion est la radio depuis laquelle tu envoies tes messages, un répéteur transmet les messages, un room server tient un tableau de messages partagé, et un observer envoie ce qu'il entend.

Cette page est une sélection. Pour une liste plus longue, consulte [awesome-meshcore](https://meshcore.live/).
