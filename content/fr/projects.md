Chaque projet renvoie vers son code. Si le code n’est pas public, il renvoie vers son site. La licence est indiquée quand le code en a une. Chaque projet vient de ses propres auteurs : tu trouves la documentation et l’aide sur sa propre page. Un fork du micrologiciel est une copie modifiée de MeshCore. Ce n’est pas le micrologiciel officiel, et son comportement peut différer. Les nœuds MeshCore ont des rôles. Un companion est la radio depuis laquelle tu envoies tes messages. Un répéteur relaie les messages. Un room server tient un tableau de messages partagé. Un observer met en ligne ce qu’il capte.

Cette page présente une sélection. Pour une liste plus longue, consulte [awesome-meshcore](https://meshcore.live/).
