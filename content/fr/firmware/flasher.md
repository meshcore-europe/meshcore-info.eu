Choisis ta carte et son rôle. Un companion est le nœud depuis lequel tu envoies tes messages, via Bluetooth ou USB. Un répéteur relaie les messages. Un room server conserve les messages pour un groupe. La version MeshCore la plus récente est sélectionnée pour toi. Le micrologiciel provient des versions publiées par MeshCore sur GitHub. Ce site transmet le fichier et n'y change rien.
