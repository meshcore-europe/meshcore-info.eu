Komando hauek MeshCore firmwarearen 1.18.0 bertsiokoak dira, firmwarearen iturburu-kodetik irakurriak. Azken bertsio batean gehitutako komandoak adierazten du zein bertsio behar duen. Errepikagailuak mezuak birbidaltzen ditu, room serverrak talde baten argitalpenak gordetzen ditu, eta sentsoreak neurketak bidaltzen ditu. Room serverrek, sentsoreek eta companionek komando asko dituzte komunean. Komando bakoitzean ikusiko duzu zein nodok duten. "Zein nodo?" aukerarekin zure nodoaren komandoak bakarrik ikusiko dituzu.

Errepikagailu, room server edo sentsore batean, komandoak ordenagailutik idazten dituzu USB bidez, adibidez webgune honetako [serieko kontsolan](/firmware/console/). MeshCore aplikazioak mesh sarearen bidez bidaltzen ditu. [Errepikagailuaren gidak](/repeater-guide/#config) bi bideak erakusten ditu.

1.18 bertsiotik aurrera, companionak (mezuak bidaltzeko erabiltzen duzun nodoa, telefonoarekin edo ordenagailu eramangarriarekin parekatuta, edo bere pantailarekin) komando-lerroa ere badu. Ireki Command Line MeshCore aplikazioaren ezarpenetan, 1.50 bertsioan edo berriagoan. Remote CLI baimena duen kontaktu batek komando berak bidal diezazkioke zure companionari mesh sarearen bidez. Horien artean daude WiFi eta PIN komandoak ere.

Komando baten hasierako balioa errepikagailuarena da. Room server, sentsore edo companion bat beste balio batekin has daiteke. Companionak bakarrik duen komandoak bere balioa erakusten du.
