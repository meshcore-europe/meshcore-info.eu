Спостерігач (observer) це вузол, який ще й передає почуте через MQTT по Wi-Fi. Кожен спостерігач показує трохи більше mesh-мережі в
[MeshCore Analyzer](https://meshcore-analyzer.eu/) і на
[картах покриття](/map/). За цим посібником ти перетвориш на спостерігача ретранслятор (вузол, який передає повідомлення далі). Вузол і надалі ретранслює повідомлення, а звіти йдуть лише в один бік: у mesh-мережу нічого не повертається.

{{< callout type="warning" >}}
Цей посібник стосується **прошивки DMC observer**. Це збірка
[Dutch-MeshCore](https://github.com/Dutch-MeshCore/MeshCore) для спостерігачів на основі MeshCore 1.18.0. У стандартному MeshCore немає MQTT. Усі команди нижче взято з вихідного коду прошивки, збірка `32dd8ad` від 19 жовтня 2026 року.
{{< /callout >}}

## Що тобі потрібно {#need}

- Плата ESP32 з Wi-Fi, наприклад Heltec V3 або V4, LilyGo T3S3 чи Xiao S3. Усі плати перелічено в
  [релізі](https://github.com/Dutch-MeshCore/MeshCore/releases/tag/observer-mqtt-dev).
  Плати nRF52, як-от RAK4631, не мають Wi-Fi.
- Мережа Wi-Fi 2.4 GHz там, де стоїть плата.
- USB-кабель для передавання даних, а на комп'ютері Chrome, Edge або Opera.
- Код найближчого до твого вузла аеропорту: 3 літери, наприклад `AMS` або `BRU`.
  Цей код підказує брокерам (серверам, які отримують твої звіти), у якому регіоні працює твій спостерігач.

Там, де стоїть ретранслятор, немає Wi-Fi, зате поруч є комп'ютер?
Тоді [створи конфігурацію моста](/guides/mctomqtt/).

## Проший плату {#flash}

[Прошивальник](/firmware/flasher/) на цьому сайті містить лише стандартний MeshCore.
Прошивку для спостерігача ти знайдеш у прошивальнику з
[DutchMeshCore Toolbox](https://toolbox.dutchmeshcore.nl/):

1. Вибери свою плату, а потім **DutchMeshCore MQTT** (Repeater + Observer + MQTT).
2. Першого разу вибери **Full flash**: цей режим замінює все на платі, зокрема таблицю розділів. Оновлення застосунку зберігає вміст плати й годиться для наступних оновлень.
3. Налаштуй ретранслятор як завжди: назву, радіопресет і пароль адміністратора, як описано в [посібнику з ретранслятора](/repeater-guide/#config).

Це збірка **dev**. Коли ти вводиш `ota update`, вона оновлюється з каналу dev. У стабільному каналі досі версія 1.17.1, тому для цього посібника залишайся на dev.

## Налаштування {#settings}

Відкрий на цьому сайті [послідовну консоль](/firmware/console/) і підключи плату. Вкажи назву своєї мережі Wi-Fi, пароль і код аеропорту, а потім встав ці рядки по одному:

```text
set wifi.ssid MyNetwork
set wifi.pwd MyPassword
set mqtt.iata AMS
reboot
```

Після перезавантаження плата підключається до твоєї мережі Wi-Fi і налаштовує годинник через інтернет. Брокерам потрібен цей годинник, щоб перевірити, хто твій спостерігач. Без коду аеропорту звітів не буде.

Хочеш клацати мишею, а не вводити команди? Команда `start webconfig` відкриває на платі сторінку налаштувань за адресою, яку показує консоль. Для входу введи пароль адміністратора.

## Слоти брокерів {#brokers}

Один слот вміщує одного брокера. Спочатку у прошивці заповнено такі слоти:

| Слот | Брокер | Хто керує |
| --- | --- | --- |
| 1 | `dutchmeshcore-1` | Dutch-MeshCore |
| 2 | `dutchmeshcore-2` | Dutch-MeshCore |
| 3 | `meshcore-analyzer-eu` | MeshCore Analyzer |

Плата без додаткової пам'яті (PSRAM), наприклад Heltec V3, має 3 слоти. Одночасно вона підключається до 2 з них, тому Analyzer у слоті 3 ніколи не підключиться.
Перенеси його в слот 1:

```text
set mqtt3.preset none
set mqtt1.preset meshcore-analyzer-eu
```

Плата з PSRAM, наприклад Heltec V4, має 6 слотів і підключається одночасно до 5. Тут нічого змінювати не треба.

На кожен брокер твій вузол входить зі своїм ключем, тому обліковий запис тобі не потрібен.
Команда `get mqtt.presets` показує інших брокерів спільноти, яких знає прошивка.

### Власний брокер {#own}

Додай власного брокера у вільний слот. Вкажи його адресу, порт, ім'я користувача й пароль. На платі з PSRAM вільний слот 4:

```text
set mqtt4.preset custom
set mqtt4.server mqtt.example.org
set mqtt4.port 1883
set mqtt4.username my_username
set mqtt4.password my_password
```

На платі без PSRAM використай натомість слот 2: заміни `mqtt4` на `mqtt2`.
Тоді твій брокер займе місце `dutchmeshcore-2`.

Через порт `8883` з'єднання зашифроване (TLS), через порт `443` зашифроване поверх вебз'єднання (websocket), а через будь-який інший порт не зашифроване. Ти також можеш указати повну адресу, наприклад `wss://mqtt.example.org:9002/mqtt`. Тоді це правило для портів не діє.

## Перевір, чи все працює {#check}

Введи `get mqtt.status`. Для кожного слота ти побачиш його стан:

```text
> msgs: on, 1: meshcore-analyzer-eu (ok), 2: dutchmeshcore-2 (ok), q:0
```

- `ok`: підключено.
- `wait`: у слоті бракує налаштування, наприклад коду аеропорту.
- `disc`: ще не підключено. Перевір Wi-Fi командою `get wifi.status`.
- `fail`: слот не зміг підключитися 7 разів поспіль упродовж приблизно 20 хвилин. Тепер він пробує раз на 30 хвилин. Перевір адресу брокера й дані для входу.
- `inactive`: на платі немає місця для цього слота. Дивись
  [Слоти брокерів](#brokers).

Потім пошукай назву свого ретранслятора на
[сторінці спостерігачів в Analyzer](https://meshcore-analyzer.eu/#observers).
Ретранслятор з'явиться там протягом 5 хвилин разом із тим, що він почув.
