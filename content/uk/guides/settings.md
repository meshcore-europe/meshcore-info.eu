Кожна місцевість нижче використовує власний радіопресет або змінює кілька стандартних
налаштувань MeshCore. Усе, чого немає в переліку, залишається стандартним, тож
ти змінюєш лише те, що змінили у твоїй місцевості. Ретранслятор передає
повідомлення далі для всіх; компаньйон є вузлом, з якого ти пишеш повідомлення.
Він працює в парі з телефоном або ноутбуком через Bluetooth чи USB або має власний екран.

У [посібнику з ретрансляторів](/repeater-guide/#config) показано, як відкрити
командний рядок ретранслятора, а в [послідовній консолі](/firmware/console/) на
цьому сайті ти вводиш команди власноруч. Під кожною місцевістю ти також можеш
надіслати її налаштування через USB. У посібнику з ретрансляторів також наведено
[законодавчі обмеження](/repeater-guide/#legal) для 868 MHz.

## Менше трафіку в ефірі {#traffic}

Ці налаштування діють для кожної місцевості. Кожен ретранслятор передає далі
кожне flood-повідомлення, яке чує. Одне твоє повідомлення потребує однієї передачі
і ще по одній від кожного ретранслятора, який його почує. За duty cycle 10%
ретранслятор може надіслати близько 680 пакетів на годину, і це число ділять між
собою всі навколо нього. Повідомлення, яке йде далі, ніж потрібно, витрачає
частину цього запасу.

**Надсилай у найменший регіон, що охоплює тих, кому ти пишеш.**
Регіони вкладені один в одний: країна, область, місцева група. Кожен має власний
код, наприклад `nl`, `nl-ov` і `nl-ov-zwo`. Повідомлення для `nl-ov-zwo`
залишається серед ретрансляторів цієї групи. Ретранслятор передає далі лише ті
регіони, які має сам: якщо в нього є `nl`, це ще не означає, що він передаватиме `nl-ov`.
Додай кожен ретранслятор до всіх регіонів, які він обслуговує, і лише до них;
твоя [місцева група](/community/) знає, які це регіони.

**Обмеж те, що передає далі твій ретранслятор.** Два налаштування тримають
поблизу трафік, якому немає потреби йти далеко:

```text
set flood.max.advert 3
set flood.max.unscoped 1
```

- `flood.max.advert 3`: оголошення, якими вузол заявляє про себе в мережі,
  проходять щонайбільше 3 стрибки.
- `flood.max.unscoped 1`: повідомлення без регіону проходить щонайбільше через
  один ретранслятор.
