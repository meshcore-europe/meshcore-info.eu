Ці команди відповідають прошивці MeshCore 1.18.0 і взяті з її вихідного коду.
Біля команди, доданої в нещодавній версії, вказано потрібну версію. Ретранслятор
передає повідомлення далі, сервер кімнати зберігає дописи для групи, датчик
надсилає показники. Сервери кімнат, датчики й компаньйони мають багато спільних команд.
Біля кожної команди вказано, на яких вузлах вона є. «Який вузол?» показує лише
команди твого вузла.

На ретрансляторі, сервері кімнати чи датчику ти вводиш їх через USB зі свого комп'ютера, наприклад у [послідовній консолі](/firmware/console/) на цьому сайті. Застосунок MeshCore надсилає їх через меш-мережу.
[Посібник із ретранслятора](/repeater-guide/#config) описує обидва способи.

Від версії 1.18 командний рядок має й компаньйон (вузол, з якого ти пишеш повідомлення, спарений із телефоном чи ноутбуком або з власним екраном).
Відкрий Command Line у налаштуваннях застосунку MeshCore версії 1.50 або новішої.
Контакт із дозволом Remote CLI може надсилати твоєму компаньйону ті самі команди через меш-мережу.
Серед них є й команди для WiFi та PIN.

Початкове значення команди вказане для ретранслятора. На сервері кімнати, датчику чи
компаньйоні воно може бути іншим. Команда, яка є лише на компаньйоні, показує власне значення.
