## Was diese Website nicht tut {#not}

- Sie nutzt keine Analyse-, Statistik- oder Tracking-Skripte, weder eigene noch fremde.
- Sie lädt ihre Schriften, Styles und Skripte nur von dieser Website. Es gibt keine
  eingebetteten Videos von anderen Websites, keine Social-Media-Buttons und keine Werbung.
- Sie hat keine Konten und keine Kommentare. Die zwei Formulare auf der Website, der
  Schlüsselgenerator und die Kanalauswahl, senden nichts an uns.

## Was in deinem Browser bleibt {#browser}

Wenn du im Theme-Menü „System folgen“, „Dunkel“ oder „Hell“ wählst, speichert
dein Browser diese Wahl 1 Jahr lang in einem Cookie namens `dmc-mode`. Das
Cookie gilt für meshcore-info.eu und seine Subdomains. Dadurch öffnet sich jede
Seite so, wie du es gewählt hast. Das Cookie enthält nur dieses eine Wort.
Wenn du nie etwas wählst, setzt die Website kein Cookie. Lösche die
Website-Daten in deinem Browser, um es zu entfernen.

Die Startseite merkt sich für diesen Tab auch, dass du ihren Eröffnungsfilm
gesehen hast. Ein zweiter Besuch im selben Tab startet deshalb direkt beim
Inhalt. Dieser Vermerk verschwindet, wenn du den Tab schließt.

Auf einer Seite mit Checkliste, etwa der
[Checkliste für den Aufbau](/repeater-guide/#checklist), speichert dein Browser,
welche Punkte du abgehakt hast. So sind sie noch abgehakt, wenn du
zurückkommst. Sie bleiben auf deinem Gerät, bis du den Haken wieder entfernst.

Die Startseite liest die bevorzugten Sprachen deines Browsers aus und öffnet
die passende Sprachversion der Website. Diese Prüfung läuft in deinem Browser
und sendet nichts. Sobald sie eine Sprache gewählt hat oder du eine im
Sprachmenü wählst, speichert dein Browser diese Sprache auf deinem Gerät. Die
Startseite öffnet sich dann beim nächsten Mal in dieser Sprache, ohne den Hinweis
zur Sprache. Lösche die Website-Daten in deinem Browser, um sie zu entfernen.

## Was die Website bei anderen Servern abfragt {#requests}

Die Startseite und die Seite „Netzwerk“ zeigen Live-Zahlen von
[meshcore-analyzer.eu](https://meshcore-analyzer.eu). Diesen Server betreibt
dieselbe Gruppe von Freiwilligen. Die Seite „Kanäle finden“ fragt diesen Server
nach den Kanälen des Landes, das du wählst. Jede Anfrage enthält deine
IP-Adresse sowie Name und Version deines Browsers (den User-Agent). Auf
„Kanäle finden“ enthält sie auch das Land, das du gewählt hast. Keine andere
Seite kontaktiert einen anderen Server.

## Was unser Hoster sieht {#host}

Cloudflare, ein Hosting-Unternehmen, liefert dir jede Seite aus. Dafür
verarbeiten die Server von Cloudflare deine Anfrage. Diese Anfrage enthält deine
IP-Adresse, die Adresse der Seite und den User-Agent deines Browsers, wie bei
jedem Webserver. Die [Datenschutzerklärung](https://www.cloudflare.com/privacypolicy/)
von Cloudflare beschreibt, wie Cloudflare mit diesen Daten umgeht. Cloudflare
bittet deinen Browser auch, eine fehlgeschlagene Verbindung an Cloudflare zu
melden. So erkennt Cloudflare Ausfälle.

Die Freiwilligen, die diese Website betreiben, schalten die Web-Analyse von
Cloudflare nicht ein. Sie haben keinen Zugriff auf Logs einzelner Besucher.

## Links zu anderen Websites {#links}

Links auf dieser Website führen zu lokalen Gruppen, Karten, Projekten,
Herstellern und GitHub. Sobald du einem folgst, gilt die Datenschutzerklärung
der jeweiligen Website. Die Links „Diese Seite auf GitHub bearbeiten“ führen
dich zu GitHub.

## Fragen {#questions}

Eröffne ein Issue auf [GitHub](https://github.com/meshcore-europe/meshcore-info.eu/issues),
wenn etwas auf dieser Seite unklar oder nicht mehr richtig ist.
